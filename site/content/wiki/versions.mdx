Spelunky Classic is Derek Yu's game, made with GameMaker 7.0 and 8.0, as the game's `readme.txt` says. That file's
version history names 1.0 and 1.1, and mentions betas before them; 1.1 is the last it names. This wiki describes
1.1 only: its pages are cited to 1.1's source, and their clips are recorded from the spelunky.ai port, which plays
1.1 exactly, bugs included. The readme also announces a version for Xbox Live Arcade, for 2010: that game, and the
ones after it, are other games with other rules, and the wiki leaves them out.

## How it works

### 1.0 and the betas

The readme's version history starts at 1.0, released on 1 September 2009 as the "first non-beta version". It points
to the developer's forum for a full list of changes from v0.96.1 on, and its thanks name v0.97 and v0.99.9. None of
the betas' files came with 1.1, so the wiki doesn't cover them.

### 1.1

1.1 came out on 25 December 2009, and the source with it. The readme's entry for it lists no changes. The game's
files are the game, `Spelunky.exe`; the [[settings|settings]] program, `config.exe`; `supersound.dll`, the library
that plays its music and sounds; the `sound` folder; an empty `levels` folder for the [[level-editor|level
editor]]'s levels; the three settings files; the readme; and the license, `COPYING.txt`.

The source is two GameMaker files, `spelunky.gmk` (the game) and `config.gmk` (the settings program), with a readme
of its own. Derek Yu released it, as that readme puts it, "in the hopes that you can learn from it and create some
cool stuff of your own". The [[credits|credits]] name the others whose work is in it: Martin Piecyk's platform
engine and ChevyRay's screen scaling code, and the readme adds tsg1zzn's Super Sound System, the scripts that drive
`supersound.dll` <Cite gml="scripts/SS_Init.gml:1-20" />.

### Left in 1.1

The source keeps a few things 1.1 doesn't use:

- **The version on the title screen.** The [[title-screen|title screen]]'s code has the text V1.1 (C)2009, but commented out, so the
  title screen shows no version <Cite gml="objects/oTitle/draw.gml:11-15" />.
- **Flares.** The game still keeps a count of 3 [[flare|Flares]], "not used any
  more" <Cite gml="scripts/scrClearGlobals.gml:115" />, and reads a flare key that nothing checks: the line that
  would is commented out ([[controls]]) <Cite gml="objects/oPlayer1/step.gml:413" /> <Cite quirk="1" row="The flare key is read but never checked." />. The
  readme's thanks mention flares in v0.99.9.
- **The settings program's key screens.** The game's own file has a copy of the settings program's key and gamepad
  screens, which nothing in the game reaches <Cite gml="objects/oKeyConfig/keypress_anykey.gml:54" /> <Cite quirk="1" row="Dangling references to config.exe resources" />.
- **The sound library's demo.** Objects from the Super Sound System's demo are still in the game, one loading a
  music file the game doesn't ship, in a room of their own, the last, which nothing goes
  to <Cite gml="objects/core/create.gml:1-6" /> <Cite room="room0" /> <Cite quirk="1" row="SuperSound demo leftovers" />.

### The license

Both the game and its source are under the Spelunky User License v1.1b, which the readme sums up as: "You can
redistribute and/or modify Spelunky, including its source code, under the terms of the Spelunky User License. You
may not sell Spelunky." The source's own scripts start with the copyright
notice <Cite gml="scripts/scrClearGlobals.gml:8-23" />.

### The spelunky.ai port

The port this wiki's clips come from is a version of 1.1 rebuilt from its source, for macOS, Windows, Linux and the
web. It plays 1.1 exactly, step for step, including its bugs, and its own releases are numbered from 0.1.0 so that
they're never mistaken for the original's. The line under each page's title names the port's release the page was
last checked against.
