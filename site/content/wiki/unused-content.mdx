The game's files define about thirty objects that nothing in Spelunky Classic 1.1 ever makes: no room
places them, and nothing that runs creates them, so no player meets them. Their code is still
there, and says what each would do. A few are items, a target and a trap; the rest are blocks, effects
and the settings program's controls, which the game's files carry too. Each is in a row of
`docs/quirks.md`'s leftovers.

## How it works

Every object a game has comes from a room the room editor laid out or from an `instance_create` in the code
naming it. None of these appears in any of the 30 rooms' 6,330 placed instances, and no `instance_create`
names one, or names it only in a comment or in a branch no level reaches (the thwomp trap's) <Cite quirk="1" row="oJordans, oRopeBag, oBasketball and oFireFrogArmed are unreachable" />.

### The settings program's controls

The game's files carry a copy of the [[settings|settings program]]'s check boxes, radio box and volume
sliders (`oCheckBox` to `oCheckBox4`, `oRadioBox`, `oSlider1`, `oSlider2`, `oSliderBG`), and its OK, key
config and gamepad config buttons. None is in the game's rooms, so the game never shows them
<Cite gml="objects/oCheckBox/create.gml:1-6" /> <Cite quirk="1" row="Dangling references to config.exe resources" /> <Cite quirk="1" row="The rest of the game's objects that nothing makes." />.
